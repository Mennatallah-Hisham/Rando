# Speak Rando

Speak Rando helps language learners start speaking earlier and with more confidence through structured speaking prompts.

The agreed MVP scope and roadmap are documented in [BUILD_PLAN.md](BUILD_PLAN.md).

## Prerequisites

- Node.js compatible with Next.js 16
- npm

## Local setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

## Environment variables

No external integration is implemented yet, so no environment variables are required. Do not commit `.env` or `.env.local` files.
